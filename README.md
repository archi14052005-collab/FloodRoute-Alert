# FloodRoute Alert – Smart Flood Route Information System

## About the Project
FloodRoute Alert is a prototype web application designed to help people report road hazards during floods and view community-submitted information. It aims to improve awareness of possible road disruptions during emergencies.

## Problem Statement
During floods, roads may become submerged or blocked, making it difficult for people to identify affected routes and reach essential services.

## Key Features
- Interactive map with demonstration markers
- Community road hazard reporting form
- Hazard categories and severity levels
- Recent community reports section
- Reports saved in browser Local Storage
- Responsive design for desktop and mobile
- Basic flood safety information

## Technologies Used
- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. An internet connection is required to load the external map and map tiles.

## Current Limitations
- This is a demonstration prototype, not a live emergency service.
- Map markers are sample data and are not verified real-world incidents.
- Submitted reports are stored locally in the browser and are not shared with other users.
- The application does not currently verify safe routes or provide guaranteed safe navigation.
- Real-time data, user authentication, a shared database, and emergency authority integration are not implemented.

## Future Improvements
- Backend and shared database integration
- Location-based hazard reporting
- Verified updates from trusted authorities
- Notifications for affected areas
- Improved accessibility and emergency information

## Disclaimer
FloodRoute Alert is a prototype for educational and social-impact purposes. Do not use its demonstration data to make real emergency travel decisions. Follow official disaster management instructions and verified local advisories.
